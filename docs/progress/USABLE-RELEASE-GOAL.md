## 首版支持范围与完成标准

1. 保留并整合已证常用功能：主页主模式及快捷项、可靠可写CPU/Windows字段、GPU偏移/VF、灯光、预设、可靠自动化路径、设置与诊断；不重复重建已闭合点。
2. 按功能实际能力使用四级：A实机独立核验；B配置写入/可靠读回/恢复已证但没有独立实际效果遥测；C只读；D本期不支持。**B不再因缺独立效果遥测无限等待**，但它仍须有真实字段语义、量纲、读回和可恢复性，不能用回包成功或预填值冒充。
3. 采用DeepSeek首版降级方向：风扇优先EC自动/交还固件；固定RPM、曲线、联动、自动最大、强冷若时间盒内无可靠实现则本期D并隐藏相应写入口。Fan预设也只能使用本期可靠支持的范围，不能借预设触发隐藏写入。
4. GPU锁频/任意电压本期无可靠支持则D并隐藏写入口；功率限制保持真实只读。不能因隐藏少数高级功能把已证GPU偏移/VF一并删掉。
5. CPU高级字段优先复用成熟通路，允许达到B即进入首版；未知活动值不能伪造。未证字段C/D，不阻断其余可靠字段和不依赖它的AUTO目标。
6. UI只保留实际产品路径；重复V1/旧页面在确认无调用与无脚本依赖后清理。重命名、目录美化和大重构不挡首版。
7. 设置页必须提供默认关闭的“退出后保留配置修改”。关闭执行支持范围内既定退出恢复；开启正常完全退出停止全部跟随/调度，保留已应用配置，重开以当前状态建立新基线。托盘驻留不是完全退出。实际进程退出后不能宣称仍在执行动态风扇曲线或跟随。
8. 产物必须来自同一冻结源码，有GUI/Service和正式Release构建产物、版本及SHA、支持矩阵、剩余问题和简短使用说明。实际运行并完成支持范围内一次完整生命周期，不把“能编译”写成“可使用”。
9. 首版无已知会污染用户状态、越权写入、错误恢复或永久无法退出的阻断缺陷；关键测试不能通过Ignore、删断言、改成永真获得绿色。测试套件里的未定性失败必须复现并给出结论。
