# XISURA 实时控制与预设管理实施计划

目标：实时设置、保存配置、编辑草稿各自明确；设备开关直接操作；登录启动可靠；MSI 离线运行。

- [x] 共享 `PagePresetToolbar` / `ModePresetPicker`：默认实时，管理入口与返回入口；当前来源与编辑对象分开；点击档位直接使用，浏览模式不应用；另存为选择目标。
- [x] 性能：实时读回与实时调整不受自动跟随开关影响；管理态缓存草稿；保存并应用；当前值另存为。
- [x] GPU / 风扇：同一规则，曲线保留显式应用；MUX 独立提交，旧预设不自动改变输出。
- [x] 灯光：自动跟随只处理模式变化；管理草稿不写硬件；手动设置不被轮询覆盖。
- [x] 模式 / 自适应：手动模式暂停自动控制；编辑器不被硬件观察和自动跟随覆盖；保持模式失败和回滚的真实结果。
- [x] 自启动：当前用户交互式最高权限登录任务；迁移旧 Run；电池供电不阻止；开关核对真实登记。
- [x] 安装：内置 .NET 与 Windows App Runtime；修复 MSI 语言元数据校验；验证离线依赖、安装升级、单实例及真实窗口。
- [x] 客户端 436/436、安装包 14/14；实际安装、预设草稿隔离、自启动单实例及 EC 灰显验收通过。
- [x] 私人仓库已发布 v1.0.68 最终 MSI；GitHub 资产 SHA256 与本机一致。

约束：保留已保存配置、默认数值与各页自动跟随偏好；未知硬件值不伪造；不绕过固件保护；本轮不重画视觉布局。工作树有既存改动，发布使用已有精选快照。
