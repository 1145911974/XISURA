# XISURA 1.0.75 修复验收

日期：2026-10-06；Windows 11 x64，蛟龙 16 Pro 2023，双屏。

| 问题 | 修复与证据 |
|---|---|
| GPU 首次限频无法输入 | 保留目标输入和滑条；有效范围同步到滑条；未知读回单独标注。安装版无提交状态下输入 3105 MHz、滑条均 enabled；没有实际提交此目标。 |
| 保存预设后自适应持有旧值 | 保存、恢复默认事件重新请求服务配置，重新读取预设；保留配置版本和失败重试。调用链回归通过，未在本轮启用自适应进行实机写入。 |
| GPU 探测错误永久缓存 | 错误冷却 10 秒后重试，成功继续缓存；取消不延长错误缓存。故障、恢复、成功缓存、取消测试通过。 |
| 风扇不可用仍可保存并应用 | 保存与应用分别判断；编辑和保存不依赖硬件能力，应用要求连接和风扇能力。所有加载、重置、保存和应用出口统一更新可用性。 |
| EC 模式曲线帮助被禁用 | 保留灰色参考曲线，仅禁用编辑控件，帮助仍可用。安装版确认曲线数值编辑禁用、问号启用。 |
| 依赖入口创建空目录 | 两个设置入口统一打开实际程序安装目录；标签改为“程序与依赖文件”。目录断言通过。 |
| 完全卸载遗留开机任务 | 仅完整卸载、非升级时清理；要求产品任务前缀、唯一 Exec 动作、匹配本安装的客户端路径。实际卸载验证清理成功，重新安装后原开机任务原样恢复。 |
| 本地快捷项误报设备不可用 | Win 键、CapsLock、NumLock、息屏统一按 Windows 本地功能判定；编辑器与托盘共享规则。安装版三个锁定功能无“当前设备不可用”标注；未改变用户选择、顺序或六项上限。 |

## 验证

- 10 个测试项目：663 通过、0 失败；排除 `CurrentMachine` 分类。新增 8 个测试方法。
- 最终 MSI 安装退出 0；客户端和服务 DLL 与发布载荷 SHA-256 一致；服务 Running、客户端响应正常。
- 七个页面均响应；二次启动退出 0，原实例仍在且总数为 1。
- 两个实际显示器：托盘点击位置决定弹出屏幕；内部点击保持显示，外部点击收纳；收纳中间帧仍可见且透明度介于 0–255；跨屏快速重开完成后透明度 255。
- 更新过程中正常退出；完整卸载清理测试未要求删除用户数据；恢复原登录任务。
- 硬件写入失败、风扇能力缺失的分支由测试替身或调用链检查覆盖；本轮没有切换 MUX、改变硬件目标或覆写用户预设。三屏、四屏、冷重启及干净虚拟机仍不属于本轮实机验证。

## 绘制开销

曲线路径、裁切几何和 GPU 仪表几何复用；温度标记复用画刷。曲线和风扇数值绘制限制至 30 帧/秒，保留过渡和曲线断点。

采样按进程 CPU 时间 / 墙钟时间 / 16 个逻辑处理器计算，每页 6 秒；1.0.75 分别采样初次与稳定运行状态，报告范围而非保证值。

| 页面 | 1.0.74 | 1.0.75 |
|---|---:|---:|
| 首页 | 7.04% | 1.62%–3.09% |
| 设置 | 0.33% | 0.39%–1.97% |
| 显卡 | 6.34% | 1.72%–3.88% |
| 风扇 | 3.43% | 2.15%–4.16% |

性能采样来自包含全部绘制修复的安装版；随后仅追加快捷项可用性修复。稳定运行的首页、显卡页开销明显下降，初次运行与实际负载仍会影响结果。

任务枚举依据：[Microsoft ITaskFolder.GetTasks](https://learn.microsoft.com/en-us/windows/win32/api/taskschd/nf-taskschd-itaskfolder-gettasks)。卸载只处理已确认属于本安装的任务，升级保留任务。
