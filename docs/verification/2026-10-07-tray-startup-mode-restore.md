# 1.0.78 静默启动与模式恢复

- 首次启动不激活主窗口，先注册托盘、启动服务连接和状态恢复；窗口加载不再强制显示。
- 硬件按键及自适应的已确认模式持久化；相同模式保留原调节配置，变化模式丢弃旧模式的 CPU/GPU/风扇覆盖。过期轮询不能覆盖新模式确认。
- 自适应开启也恢复上次模式；CPU/GPU/风扇旧覆盖继续由自适应隔离。供电、硬件能力、手动新请求及失败恢复保护保持有效。
- 策略后台同步等待恢复结束；用户启用和后台发布通过同一互斥锁串行确认，保存偏好仍以服务读回为准。
- 重复启动打开已有窗口，单实例保持；启动任务无登录延迟并保留登记。
