# XISURA 1.0.71 · CO 实时选择回读修复

- 根因：ApplyHardwareState 每次 ApplyDraft(null)，丢弃硬件 CO 数值并重设 BIOS；实时等待人工控制交接时，旧回读也可覆盖编辑器。
- 改为从 hardwareReadback 的完整 8 核数值重建曲线草稿。统一数值与已选全核/逐核方式保持一致，非统一回读转为逐核；缓存/缺失/越界回读不冒充 0 或 BIOS。
- 沿用 BIOS 保留“不额外写 CO，也不撤销旧偏移”的语义。保存/编辑预设与当前电脑的方式分开；成功应用后记忆相应方式。
- 实时操作从交接开始至应用结束阻止回读覆盖；结束后恢复控件可用状态。
- 客户端 440/440、MSI 14/14。扩展既有 CO 测试，覆盖全核/逐核/BIOS、0、非统一硬件、缓存/缺失/非法值与快照隔离；新增测试方法数 0。
- 安装版 1.0.70→1.0.71.0 升级退出 0，服务 Running，窗口 Responding，客户端/服务 DLL 与新自包含载荷相同。
- 原生检查：硬件现值 0，切全核后连续 7 秒每秒检查均为全核/0；跨页面不复位；BIOS 方式及第二次全核切换稳定；应用后控件恢复可用。结束恢复原 BIOS 选项，未改变偏移数值。
- 本轮未做非零 CO 硬件写入、冷重启或无运行库虚拟机验证。构建仍有既有 3 个工具链警告、0 错误。
